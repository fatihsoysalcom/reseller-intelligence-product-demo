# Reseller Intelligence Product Demo

This Python script demonstrates a business model where a core intelligence product is sold to resellers, who then package and sell it to end-clients. It simulates a base analytics engine and a reseller that uses it to provide branded insights.

## Language

`python`

## How to Run

Save the code as `reseller_intelligence.py` and run it from your terminal using `python reseller_intelligence.py`.
